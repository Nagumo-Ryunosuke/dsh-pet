# 灵魂数据库卸载观察

隔离临时配置的 Windows 测试中，宿主卸载后、进程仍运行时，SQLite 数据目录无法删除；进程退出后可以删除。当前 `createRealSoul` 持有数据库句柄，尚未发现宿主卸载时关闭它的路径。长时间运行的宿主反复重载插件可能累积句柄或妨碍删除数据；进程退出时操作系统会回收句柄。

安全关闭尚未实现。不能在现有卸载回调中直接关闭数据库：渠道停止目前异步触发且未等待排空，模型调用结束后仍可能写库。后续设计需阻止新调用并跟踪、排空 QQ `channelSoul.respond`、宿主聊天和相关模型调用、事实抽取与摘要维护，以及绑定和记忆管理等数据库入口；还应考虑定时器停用后已启动的维护任务。完成排空后再关闭句柄，并覆盖在途调用、重复卸载和关闭失败的测试。
